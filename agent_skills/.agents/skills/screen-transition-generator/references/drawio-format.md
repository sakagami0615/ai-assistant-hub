# draw.io 出力形式

## ファイル

- `screen-transition.drawio`（非圧縮の mxGraph XML。draw.io / diagrams.net / VS Code の Draw.io Integration で開ける）
- スクリーンショットは PNG のまま `image=data:image/png,<base64>` で埋め込む（ファイル単体で開ける）。同じ画像を `images/` にも保存する。
- 画像は圧縮・縮小しない（可読性を優先）。画面数が多いとファイルが大きくなる（summary.md にサイズを表示）。

## 画面ノード

- `shape=image` の vertex。ラベル（画面名）は画像の下。
- 表示サイズ = 原寸 × `display.scale`（既定 0.5）。原寸 PNG を埋め込んでいるので、draw.io で拡大すれば文字が読める。
- 外部画面は点線枠・灰色の文字。

## 矢印（ボタン位置から遷移先へ）

```text
style="edgeStyle=orthogonalEdgeStyle;rounded=1;...;startArrow=oval;startFill=1;
       exitX=<ボタン中心x/画像幅>;exitY=<ボタン中心y/画像高さ>;exitDx=0;exitDy=0;exitPerimeter=0;"
source="<遷移元画面ID>" target="<遷移先画面ID>"
```

- 起点は画像に対する **相対座標**（0〜1）。draw.io 上で画像を移動・拡大縮小しても、矢印はボタン位置から出続ける（mxGraph での移動・リサイズ後の起点位置を検証済み）。
- 起点に丸いマーカーを描き、どのボタンからの遷移かを示す。
- ラベル = 操作したボタン・リンクの表示名。
- 浅い層へ戻る遷移（例: 「最初に戻る」）は破線。
- 同じ遷移元から同じ遷移先へ複数のボタンがある場合は、ボタンごとに別の矢印。

## 共通ナビゲーションの集約

ヘッダーのメニューなど、同じ（role・ラベル・遷移先）の矢印が複数の画面から出ている場合（`display.collapseCommonActions: true`、既定）:

- 遷移元の深さが最も浅い 1 本（同じ深さなら画面 ID が小さい方）だけを表示し、ラベルに「（他 N 画面からも）」を付ける。
- 残りはレイヤー「共通ナビゲーション（全件）」（初期状態は非表示）に入れる。draw.io の「表示 → レイヤー」（Ctrl+Shift+L）で表示を切り替えられる。
- 探索・検証は全件行っている。graph.json では `collapsed: true` が付く。

## レイアウト

- 開始画面からの操作回数（BFS 深さ）ごとに層を作り、上から下へ並べる。
- 層の中は重心法（上下に数回掃引）で、つながる画面同士が近くなるよう左から右へ並べる。外部画面は層の右端。
- 画面同士は重ならない。層間 200px・画面間 160px の余白。
- 決定的（同じ graph.json からは同じ図）。

## 制限事項と draw.io での調整方法

- 矢印は障害物を避けない。他の画面の上を横切る場合がある（矢印は画像より手前に描画される）。矢印を選択してウェイポイントを動かすか、「配置 → レイアウト」機能を使って調整する。
- 1 つの層に画面が多いと図が横に長くなる。`display.scale` を小さくすると全体が縮む（画像は原寸のまま埋め込まれる）。
- 画面名は `graph.json` の `screens[].name` を編集して `stg generate` を再実行すると変えられる（再探索不要）。
- 生成後に draw.io 上で行った編集は、再実行すると引き継がれない（毎回新規生成。前回分は `.history/` に退避）。
