# draw.io 出力形式

## ファイル

- `screen-transition.drawio`（非圧縮の mxGraph XML。draw.io / diagrams.net / VS Code の Draw.io Integration で開ける）
- スクリーンショットは PNG のまま `image=data:image/png,<base64>` で埋め込む（ファイル単体で開ける）。同じ画像を `images/` にも保存する。
- 画像は圧縮・縮小しない（可読性を優先）。画面数が多いとファイルが大きくなる（summary.md にサイズを表示）。

## 画面ノード

- `shape=image` の vertex。ラベル（画面名）は画像の下（画像幅で折り返し）。
- 表示サイズ = 原寸 × `display.scale`（既定 0.5）。原寸 PNG を埋め込んでいるので、draw.io で拡大すれば文字が読める。
- 外部画面は点線枠・灰色の文字。

## 文字サイズ

画像の表示幅に比例させ、画像に対して文字が小さくなりすぎないようにする（`display.scale` を変えても比率は一定）。

| 対象 | サイズ | 例（表示幅 960px） |
|---|---|---|
| 画面名 | 表示幅 × 0.03（太字） | 29px |
| 矢印ラベル | 表示幅 × 0.022（白背景） | 21px |

## 矢印（ボタン位置から遷移先へ）

```text
style="edgeStyle=none;rounded=1;...;startArrow=oval;startFill=1;
       exitX=<ボタン中心x/画像幅>;exitY=<ボタン中心y/画像高さ>;exitPerimeter=0;
       entryX=<入口x>;entryY=<0:上辺 / 1:下辺>;entryPerimeter=0;"
<mxGeometry relative="1" x="<ラベル位置>"><Array as="points"><mxPoint .../>...</Array></mxGeometry>
```

- 起点は画像に対する **相対座標**（0〜1）。draw.io 上で画像を移動・拡大縮小しても、起点はボタン位置に追従する（mxGraph で検証済み）。起点に丸いマーカーを描く。
- 経路はスクリプトが計算したウェイポイントで固定する（`edgeStyle=none`。draw.io に再ルーティングさせない）。
- ラベル = 操作したボタン・リンクの表示名。最初の水平区間の起点寄りに置く。
- 浅い層へ戻る遷移（例: 「最初に戻る」）は破線。
- 同じ遷移元から同じ遷移先へ複数のボタンがある場合は、ボタンごとに別の矢印。

### 経路のルール（他の画面の上を通さない）

画面はグリッド（行 × 列）に並び、行間・列間を「通路」とする。矢印は通路だけを通る直交経路。

| 遷移先 | 出る辺 | 入る辺 |
|---|---|---|
| 下の行 | 遷移元の下辺 | 遷移先の上辺 |
| 上の行 | 遷移元の上辺 | 遷移先の下辺 |
| 同じ行 | 遷移元の下辺 | 遷移先の下辺 |

1. ボタン位置から、出る辺の外側の水平通路まで垂直に進む（この区間だけ遷移元の画像に重なる）。
2. 隣の行への遷移なら、その水平通路を進んで遷移先の入口の真上（真下）へ。離れた行への遷移なら、遷移先側の列間の垂直通路を通って、入る辺の外側の水平通路へ移る。
3. 入口から遷移先へ垂直に入る（この区間だけ遷移先の画像に重なる）。

- 同じ通路を通る矢印はレーンをずらし、同一直線上で重ならない。ラベルを含めて区間が重ならない矢印どうしだけが同じレーンを共有する（ラベル同士は 40px 以上離す）。
- 同じ遷移先・同じ辺に入る矢印は、入口を辺の 20〜80% の範囲に、到来方向の順で等間隔にずらす。
- 通路の幅は必要なレーン数から決める。層の境目の通路は、同じ層の折り返し行の間より 1.5 倍広い。
- 「他の画面を通過しない」「ラベルが画面に重ならない」「通路で重ならない」は自動テスト（ランダムなグラフを含む）で検証している。

## 共通ナビゲーションの集約

ヘッダーのメニューなど、同じ（role・ラベル・遷移先）の矢印が複数の画面から出ている場合（`display.collapseCommonActions: true`、既定）:

- 遷移元の深さが最も浅い 1 本（同じ深さなら画面 ID が小さい方）だけを表示し、ラベルに「（他 N 画面からも）」を付ける。
- 残りはレイヤー「共通ナビゲーション（全件）」（初期状態は非表示）に入れる。draw.io の「表示 → レイヤー」（Ctrl+Shift+L）で表示を切り替えられる。
- 探索・検証は全件行っている。graph.json では `collapsed: true` が付く。

## レイアウト

- **上から下（優先度 1）**: 開始画面からの操作回数（BFS 深さ）ごとに層を作り、上から下へ並べる。
- **左から右（優先度 2）**: 層の中は重心法（上下に数回掃引）で、つながる画面同士が近くなるよう左から右へ並べる。外部画面は層の最後。
- 1 行は最大 `display.maxColumns` 枚（既定 3）。超える層は次の行へ折り返す（端数の行は中央寄せ）。図は縦長になる。
- 列は全行で揃える（列間の垂直通路が上から下まで通る）。画面同士は重ならない。
- 決定的（同じ graph.json からは同じ図）。

## 制限事項と draw.io での調整方法

- 経路のウェイポイントは固定座標。draw.io 上で画像を大きく動かすと、起点・終点は追従するが途中の経路は元の位置のままなので、矢印を選択してウェイポイントを調整する。
- 非表示レイヤー「共通ナビゲーション（全件）」の矢印は経路計算の対象外（draw.io の自動ルーティング）。表示すると画面の上を通る場合がある。
- 図の幅は `display.maxColumns`、全体の大きさは `display.scale` で調整できる（画像は原寸のまま埋め込まれる）。
- 画面名は `graph.json` の `screens[].name` を編集して `stg generate` を再実行すると変えられる（再探索不要）。
- 生成後に draw.io 上で行った編集は、再実行すると引き継がれない（毎回新規生成。前回分は `.history/` に退避）。
