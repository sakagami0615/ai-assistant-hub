# ユーザーストーリー

## ペルソナ

個人利用者: 日々の作業を簡潔に記録し、着手状況を一画面で把握したい人。

## ストーリー

### US-001: ToDoを登録する

個人利用者として、実行したい作業をToDoとして登録したい。なぜならば、やるべきことを忘れずに管理したいからだ。

### US-002: ToDoを確認する

個人利用者として、登録済みのToDoと現在のステータスを一覧で確認したい。なぜならば、作業全体の状況を把握したいからだ。

### US-003: 進捗を更新する

個人利用者として、ToDoを未着手、進行中、完了のいずれかへ変更したい。なぜならば、現在の進捗を正確に記録したいからだ。

### US-004: 不要なToDoを削除する

個人利用者として、不要になったToDoを削除したい。なぜならば、一覧を現在必要な作業だけに保ちたいからだ。

## ストーリーマップ

| 利用段階 | ストーリー |
| --- | --- |
| 記録する | US-001 |
| 状況を知る | US-002 |
| 進捗を管理する | US-003 |
| 整理する | US-004 |
