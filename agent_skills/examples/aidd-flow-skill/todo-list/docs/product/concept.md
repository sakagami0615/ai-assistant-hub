# コンセプト

## 目的

Djangoの基本要素を使い、日常の作業を簡潔に管理できるToDoリストWebアプリケーションを提供する。

## 対象ユーザー

- 自分の作業をブラウザで管理したい個人
- Djangoのモデル、フォーム、ビュー、テンプレート、テストを一通り確認したい開発者

## 解決したい課題

- やるべき作業と現在の進捗がまとまっておらず、状況を把握しにくい。
- 小規模なDjangoアプリケーションの実装例を、仕様とテストの対応を含めて確認しにくい。

## ゴール

- ToDoを追加、一覧表示、ステータス変更、削除できる。
- ステータスを未着手、進行中、完了の3段階で把握できる。
- データがSQLiteに保存され、再起動後も残る。
- 仕様、テストケース、実装の対応を追跡できる。

## 非ゴール

- ユーザー登録、ログイン、ユーザーごとのデータ分離
- ToDoタイトルの編集
- 期限、優先度、タグ、検索、絞り込み
- REST API、JavaScriptによる非同期更新
- 本番環境へのデプロイ

## 成功条件

- ブラウザからToDoの追加、一覧表示、3種類のステータス変更、削除ができる。
- 空白のみのタイトルや不正なステータスを保存しない。
- 自動テストが主要な正常系と異常系を検証する。
