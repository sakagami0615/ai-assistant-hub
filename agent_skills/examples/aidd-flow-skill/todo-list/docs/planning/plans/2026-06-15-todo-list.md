# ToDo List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** DjangoとSQLiteで、ToDoの一覧、追加、3状態の変更、削除を行える個人向けWebアプリケーションを構築する。

**Architecture:** `python:3.14`ベースのDockerコンテナでuvとDjangoを実行する。`todo_project`が設定とルートURLを持ち、`todos`アプリがモデル、フォーム、関数ベースビュー、URL、テンプレートを持つ。SQLiteは`/data/db.sqlite3`へ保存し、`todo_data`名前付きボリュームで保持する。

**Tech Stack:** Python 3.14、Django、SQLite、uv、Docker、Docker Compose、Django標準テスト

---

## File Structure

- `pyproject.toml`: Python、Django、開発依存関係、uv向けプロジェクト設定。
- `Dockerfile`: Python 3.14、uv、プロジェクト依存関係を含むイメージ。
- `compose.yaml`: Webサービス、ソースマウント、ポート、SQLiteボリュームを定義。
- `.dockerignore`: イメージへ不要なローカル生成物を送らない。
- `manage.py`: Django管理コマンドの入口。
- `todo_project/settings.py`: SQLite、テンプレート、ミドルウェア、`todos`アプリの設定。
- `todo_project/urls.py`: `todos.urls`をルートへ接続。
- `todos/models.py`: `Todo`と3種類の`Status`を定義。
- `todos/forms.py`: タイトルのトリムと検証を行う`TodoCreateForm`。
- `todos/views.py`: 一覧・追加、ステータス変更、削除のビュー。
- `todos/urls.py`: 一覧、ステータス変更、削除のURL。
- `todos/templates/todos/todo_list.html`: 単一画面のフォームと一覧。
- `todos/static/todos/styles.css`: 最小限の画面スタイル。
- `todos/tests/`: モデル、フォーム、ビュー、HTTP境界のテスト。
